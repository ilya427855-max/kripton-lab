# KRIPTON LAB — полный комплект

## Самый простой способ загрузить на GitHub

1. Скачайте ZIP и распакуйте его.
2. Возьмите файл index.html из корня архива: CSS, JavaScript и иллюстрация уже встроены в него.
3. Загрузите этот index.html в ветку main вашего репозитория, заменив прежний index.html.
4. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. После успешной публикации откройте https://ilya427855-max.github.io/kripton-lab/ и обновите страницу Ctrl+F5.

Папка source содержит все 9 исходных файлов отдельно. Она нужна для дальнейшего редактирования; для варианта одним index.html загружать её необязательно.

Firebase и Google Fonts используют интернет. Через file:// браузер может ограничивать буфер обмена и сетевые возможности; проверяйте функциональность через HTTPS-хостинг или локальный веб-сервер.

Это отдельная ветка для скачивания. При её создании main и опубликованный сайт не изменены. Код бота, секрет Firebase и служебные данные в комплект не включены.
